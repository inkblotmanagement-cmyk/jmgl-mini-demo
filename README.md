# JMGL Mini Demo

A small keyword-rule teaching demo based on the public laws of the [Jackson Moral Governance Layer](https://github.com/inkblotmanagement-cmyk/JacksonMoralGovernanceLayer).

This is **not** the real JMGL. The real layer adds embeddings and a classifier. This file is a keyword-matching teaching demo only. It is pilot-stage, has not been independently tested, and is not a safety guarantee.

## Run

```bash
python jmgl_mini.py
```

It returns `ALLOW`, `BLOCK`, `MODIFY`, or `ESCALATE`, plus the triggered law.
